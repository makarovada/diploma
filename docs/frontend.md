# Веб-интерфейс DataNorma

- **Целевой продуктовый UI** — React/Vite SPA, собирается в `client/`, раздаётся с FastAPI под **`/ui/`** (корень **`/`** перенаправляет на **`/ui/`**). Маршрутизация в приложении — hash (`/#/...`), API — **`/api/...`** с Bearer JWT.
- **Legacy / fallback** — Jinja2 под **`/app/*`** (вход **`/app/login`**). Не удалять на этапе миграции: удобно для демо без сборки фронта и для сравнения в ВКР.
- **Новые пользовательские экраны** добавлять в React (`client/src/pages/...`), с **`data-testid`** на ключевых элементах.
- **Админские / отладочные** страницы при необходимости можно временно оставлять в Jinja.

Подробности запуска и переменные окружения — в корневом [README.md](../README.md).
