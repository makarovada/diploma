# План приемочных испытаний (ПМИ)

## Сценарии

1. Login в UI и проверка роли.
2. Создание source.
3. Создание destination.
4. Создание connection.
5. Настройка streams и маппинга.
6. Включение normalization.
7. Запуск sync.
8. Просмотр run logs и run detail.
9. Обработка issue/retry.
10. Проверка RBAC ограничений.
11. Яндекс Метрика flow (`summary/visits/hits/goals_reaches`).

## Критерии приемки

- Документация соответствует текущему коду.
- В актуальном контуре отражена Яндекс Метрика, а не Unisender.
- Есть воспроизводимая инструкция запуска.
- Ключевые сценарии из списка выполняются end-to-end.
