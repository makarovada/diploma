About & FAQ

DataNorma — дипломный прототип EL-платформы с упором на российские источники (Ozon, 1С, Sheets) и нормализацию под аналитику.

Сходство с Airbyte

Визуально и по смыслу UI опирается на Airbyte (open-source EL):

  • Sources — коннекторы и каталог источников; карточка источника и sync state.
  • Destinations — в прототипе одно назначение, PostgreSQL (staging + витрина canonical_sales).
  • Connections — логические связи source→destination, статусы и история sync jobs.
  • Settings / Secrets — параметры и маскирование (как configuration with secrets).
  • Normalization — у Airbyte dbt/typing; здесь — YAML-маппинг, fuzzy, ЦБ РФ, каноническая схема.

Отличия: оркестрация через Dagster (отдельная «операционная консоль»), а не встроенный job-runner Airbyte; нет отдельного marketplace коннекторов — фиксированный набор + конфиг.

Роли

  • Администратор платформы — пользователи, роли, секреты, полный доступ.
  • Интегратор данных — staging, маппинги, запуски, cron; Dagster как консоль.
  • Аналитик — только чтение витрины и справочников.

FAQ

Засчитываются ли экраны?
Каждый пункт меню — отдельный маршрут /app/... (Jinja2), подходит под требование «экранных форм»; уточните у кафедры при необходимости.
Streamlit?
Для сравнения в ВКР: Streamlit быстрее для прототипа, но здесь выбран FastAPI + Jinja2 для явных URL и единого стека с REST API.
